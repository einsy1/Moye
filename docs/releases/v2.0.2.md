# 墨页 Moye 2.0.2

本次更新让打开即记录更直接，并方便找回本地文稿。

- 每次启动进入空白草稿并自动聚焦，旧文稿及未保存编辑仍保留。
- 复用未编辑空白草稿，避免每次启动都新增空文稿。
- “打开本地文件”下方新增历史打开列表，保留最近 30 份本地文稿，排序、去重并跨启动保存。
- 点击历史记录重新读取原文件，保留已有未保存编辑；原文件不存在时提示失败。

历史打开列表不等于版本历史。本版尚未新增 AI 逐段差异审阅、版本时间线、全文搜索与置顶、图片管理、NAS 冲突面板或参考页码定位。

## 安装与回退

macOS 13+，Apple Silicon。退出旧版，解压 Moye-2.0.2-macOS-arm64.zip 并将墨页 2.0.2.app 放入应用程序。保留旧版及备份，遇到问题可退出新版再使用旧版。应用仍为 ad-hoc 签名，未经过 Developer ID 公证。

发行附件包含应用、源码和 SHA256SUMS。两个 ZIP 与校验文件放在同一目录后执行 `shasum -a 256 -c SHA256SUMS`。

## 验证

启动与历史专项、smoke、markdown、bridge、regressions、assistant、native、titlebar 均通过；构建、签名和打包验证通过。前端使用 Chromium，原生检查使用隔离数据与模拟 WebDAV。未执行真实 AI、真实 NAS 或所有目标系统版本验收。
