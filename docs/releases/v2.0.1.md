# 墨页 Moye 2.0.1

首个公开发行版本：一款面向 macOS 的 Markdown 写作工具，结合原生窗口、即时预览、独立 Codex 文稿助手与可选 WebDAV 存储。

## 下载

- **Moye-2.0.1-macOS-arm64.zip**：macOS 13+ / Apple Silicon 应用。
- **Moye-2.0.1-source.zip**：与 v2.0.1 标签一致的公开源码。
- **SHA256SUMS**：上述两个 ZIP 的 SHA-256 校验值。

将需要核对的两个 ZIP 与 SHA256SUMS 放在同一目录，执行：

```sh
shasum -a 256 -c SHA256SUMS
```

仅下载应用时可执行 `shasum -a 256 Moye-2.0.1-macOS-arm64.zip`，将结果与 SHA256SUMS 中同名文件的值比较。

解压后打开“墨页 2.0.1.app”，或先将其放入“应用程序”。应用使用 ad-hoc 签名，尚未经过 Developer ID 签名和 Apple 公证；首次打开可能被 macOS 阻止。核对来源与校验值后，按系统“隐私与安全性”提示处理。

## 主要功能

- Markdown 写作、GFM 表格与任务列表、代码高亮、大纲、查找替换。
- 编辑 / 分栏 / 阅读视图，浅深色、字体、专注与极简设置。
- 本地文件保存保护、草稿恢复、删除归档与升级前工作区备份。
- 独立 Codex 文稿助手：选择正文、添加 PDF / DOCX / Markdown / TXT 参考资料、核对建议后应用与撤销。
- WebDAV 文件浏览、ETag 条件更新、冲突保护和离线待传。
- Markdown / HTML 导出及系统打印 / PDF。
